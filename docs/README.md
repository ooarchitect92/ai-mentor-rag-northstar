# Documentation

Use this directory as the documentation entrypoint.

| File or folder | Purpose |
| --- | --- |
| `PROJECT_STRUCTURE.md` | Repository ownership, storage boundaries, and placement rules |
| `ADMIN_OPERATIONS.md` | Admin pages, workflows, failure handling, and recovery |
| `TESTING.md` | Test strategy and release verification |
| `archive/legacy-whatsapp/` | Superseded setup notes kept only for historical reference |

Current operational instructions must live directly in `docs/`. Do not copy a
new setup guide to repository root. Move obsolete material to `archive/` and
label why it is no longer authoritative.
